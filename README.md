# 生産管理アプリ プロトタイプ

## 概要

担当者1名が使用する、SQLiteベースの生産管理デスクトップアプリです。

現在のプロトタイプでは以下が動作します。

- 生産計画の登録・編集・削除
- 製品シリーズ、製番、納期、組立工程、部品終結日、部品出庫期間の管理
- ダッシュボードで機種別・納期月別・状態別の集計
- 製番別の部品表表示
- CSV / XLS / XLSX のBOM取り込み
- BOMヘッダーの自動推定
- 取り込み列の手動割り当て
- 部品ステータス管理
- サンプルデータ投入
- SQLiteへの永続保存

## 起動方法

Python 3.11以上を推奨します。

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

macOS / Linux:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

## データ保存先

初回起動時に以下が作成されます。

```text
data/production.db
```

## BOM取り込み形式

対応形式:

- CSV
- XLS
- XLSX

自動推定対象の主なヘッダー:

- 製番 / 製造番号 / JOB_NO
- 品番 / 部品番号 / PART_NO
- 品名 / 部品名 / DESCRIPTION
- 数量 / 個数 / QTY
- 発注先 / WS / VENDOR
- 納期 / 回答納期 / DUE_DATE
- 出庫予定日
- ステータス

ヘッダー行がファイル先頭でない場合も、先頭20行から候補を推定します。

## サンプルBOM

`sample_bom.csv` を同梱しています。

## 生産計画のCSV / Excel取り込み

「生産計画」タブの **CSV / Excel取り込み** ボタンから、CSV・XLS・XLSXを取り込めます。
列順は自由で、ヘッダー名から自動判定します。判定できない列は列対応画面で手動指定できます。

必須列:
- 製品シリーズ（「シリーズ」「機種」なども認識）
- 製番

任意列:
- 顧客納期
- 組立工程
- 部品完成日／部品終結日
- 部品出庫開始日
- 部品出庫完了日
- 組立開始日
- 立会日
- 出荷予定日
- 優先度（1～5）
- 状態（計画・進行中・完了・保留）
- 備考

同じ製番がすでに登録されている場合は更新、新しい製番は追加されます。
`sample_production_plan.csv` と `sample_production_plan.xlsx` を取り込み確認用に同梱しています。

## 今回の追加仕様

- 部品表の数量は整数として取り込み・表示します。
- 部品表に「組立工程」を追加しました。
- 部品は「製番 × 組立工程 × 品番」で一意に管理されます。
- 取り込み時に「製番 × 組立工程」が生産計画に存在しない行は登録せず、警告を表示します。
- 部品表には、生産計画から取得した「部品集結目標」「出庫開始目標」と納期判定を表示します。
- 部品表タブでは、全列を部分一致で検索・絞り込みできます。列見出しのクリックによる並べ替えにも対応しています。

## Ver.1.0α Phase 1（データ構造再設計）

この版では、画面を大きく変更する前にデータベースを次の三階層へ再設計しています。

1. 生産計画（製番 × 組立工程）
2. 部品
3. 手配（1部品に対して複数工程）

### 主な変更

- 生産計画は同じ製番でも組立工程が異なれば複数登録できます。
- 部品は生産計画の内部IDへ紐付きます。
- 1つの部品に複数の手配工程を登録できる `procurements` テーブルを追加しました。
- 手配には工程順、手配区分、加工内容、発注先、納期、出庫予定日、実績入荷日、状態を保持できます。
- 旧データベースは起動時に自動移行します。
- 旧BOMの発注情報は、工程順10の「従来手配」として移行します。
- 現在の部品表画面は互換表示です。複数手配を編集・表示する専用画面は次フェーズで追加します。

### データ階層

```text
生産計画 production_orders
  └─ 部品 parts
       └─ 手配 procurements（工程順10, 20, 30...）
```

既存の `data/production.db` を使用する場合は、念のため事前にバックアップしてください。
