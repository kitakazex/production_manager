# production_manager — 生産管理アプリ（プロトタイプ）

Python / PySide6 / SQLiteで開発中の、生産計画・部品表・手配工程を横断して確認するデスクトップアプリです。

**現行版：Ver.1.0α Phase 11（試作段階）**

## 目的

製造現場で、生産計画から必要部品・手配工程を追跡し、遅延や停滞の兆候を把握しやすくすることを目指しています。将来の中心目標は、変化による影響を把握し、対策の立案・実行を支援する **「変化に強い、使えるMES」** です。

本リポジトリは開発途中のプロトタイプであり、本番工場での運用を前提とした品質保証は行っていません。

## 現行版で扱う機能

- **生産計画**：製番 × 組立工程ごとの計画登録・編集・検索、CSV / XLS / XLSX取り込み
- **部品表（BOM）**：製番・組立工程別の部品管理、BOM取り込み、列の自動推定・手動割り当て
- **手配工程**：1部品に対する複数の手配工程、発注先・納期・状態の管理
- **進捗ツリー**：生産計画 → 部品 → 手配工程の階層表示と詳細確認
- **ダッシュボード**：機種別等の集計、手配進捗・遅延要因・要対応一覧の表示
- **マスタ管理**：発注先、加工内容、手配区分、ステータス等の参照・編集
- **参照用Excel出力**：生産計画・部品表・手配情報等のExcel共有出力（Phase 11）

> **進捗率について：** 現行ダッシュボードの進捗率は主に手配工程のステータスに基づく指標です。組立作業そのものの実績進捗率とは区別が必要です。

## セットアップ・起動

Windows PowerShellで、リポジトリのフォルダから実行します。

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

macOS / Linuxでの基本的な手順：

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

※ macOS / Linuxでの動作は別途確認が必要です。

アプリはローカルの `data/production.db` にデータを保存します。DB・バックアップ・個人設定はGit管理対象から除外しています。既存DBを使う場合は、変更や移行に備えてバックアップしてください。

## ファイル取り込み

生産計画・BOM・手配工程など、画面ごとの取込機能からCSV / XLS / XLSX形式のデータを読み込めます。取り込み時に列の自動判定や手動対応を行います。

**取込の基本順序：生産計画 → BOM → 手配工程。**

このGitリポジトリには現時点でサンプルCSV / Excelを登録していません。サンプルの公開可否と内容を確認してから、別途追加する予定です。

## 既知の制約・未実装の機能

以下は **開発構想・今後の実装対象** であり、現行版に完成済みの機能として搭載されているものではありません。

- 納品 → 検査・検品 → 入庫 → 出庫待機の数量別ゲート管理
- 部品の実際の出庫履歴・部分出庫・出庫残数と組立実績の連携
- 組立予定に対する部品不足の先行予測
- 製番間の部品融通と補充依頼、影響先の追跡
- 生産計画変更の影響シミュレーション・申請・承認
- 在庫とBOM・生産計画に基づくMRP、発注数量の提案
- 倉庫・配膳・容器／RFID所在管理、AQUILA（営業支援）との連携

これらは段階的に設計・テスト・実装します。独立した出庫実績モジュールの試作は、現行アプリ本体へは未統合です。
